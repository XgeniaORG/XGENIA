# XGENIA Cloud runtime

The XGENIA Cloud Runtime is a crucial component for executing XGENIA Cloud functions.
This repository contains the code necessary to run and manage these functions seamlessly within the XGENIA ecosystem.

## Usage

The XGENIA Cloud Runtime is designed to be used in conjunction with the [XGENIA Cloud Service](https://github.com/xgeniaapp/xgenia-cloudservice).
Follow the instructions provided in the XGENIA Cloud Service repository to set up the complete XGENIA Cloud environment.
